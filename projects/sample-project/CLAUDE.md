# Sample Project (template)

This is a minimal template — copy this directory to start a new project, then replace this note with rules specific to that project.

- Inherits all rules from `projects/CLAUDE.md` and the root `CLAUDE.md`; anything written here overrides them for this directory only.
- Work is driven by `spec.md`; agents implement what the spec says and propose spec changes rather than silently diverging.
- Project-specific knowledge goes in the local `kb/` (see `kb/index.md`), which supplements and, when relevant, overrides the repository-wide `kb/`.
