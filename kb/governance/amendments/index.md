# Proposed Amendments

Each constitutional-convention session saves its output here as one file, named `session-YYYY-MM-DD.md` (append `-2`, `-3`, … for multiple sessions in a day), with `status: proposed`.

Proposals are **never applied automatically**. After owner review, ratified changes are merged into [constitution.md](../constitution.md), and the session file's status becomes `adopted` (or `deprecated` if rejected).
